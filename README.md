# AquaShield AI

Machine Learning based Water Potability Prediction System for Intelligent Water Quality Assessments.

## Features

- Data preprocessing
- Water potability prediction
- Contamination risk assessment
- Multiple ML algorithms
- Dashboard (Upcoming)

## Dataset

Water Potability Dataset from Kaggle

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
